Secure Your Code Before It Reaches Git.

CommitGuard is a fast, offline pre-commit security & SAST analysis engine. Scans only added diff lines for hardcoded credentials, AST cross-line taint flows, vulnerable packages, and dependency blast-radius — with 1-click auto-fixes.

Engineered for High Precision & Speed

Everything runs on your local CPU in milliseconds. Nothing is ever sent to the cloud.

🔑

Deep Secret Detection

300+ rules covering AWS, GCP, Azure, OpenAI, Anthropic, Stripe, SSH keys, combined with Shannon entropy and character-class adjustment to eliminate false positives.

🧠

AST Cross-Line Taint Analysis

Follows untrusted user inputs (Flask/Django request.args, env variables) across multi-line variable reassignments straight into SQL execution and shell sinks.

🔗

Dependency & Blast Radius

Parses import trees in 7+ languages (Python, JS/TS, Go, Rust, Java, etc.) and calculates the exact blast-radius of vulnerable files with native Mermaid diagrams.

⚡

1-Click Auto-Fix Engine

Don't just detect vulnerabilities — fix them. Automatically transforms insecure code (like yaml.load() to yaml.safe_load()) and git-stages the result.

📦

Free Dependency SCA

Scans project manifests (requirements.txt, package.json, etc.) against Google OSV.dev batch vulnerability data completely free with zero API keys required.

🤖

GitHub Actions & PR Bot

Generates clean SARIF reports, GitHub annotations, automated pull requests, and native click-to-commit inline suggestions on PR diffs.

Command-Line Reference

Use the lightweight ./commit-guard wrapper or invoke main.py directly.

Manual Staged Scan

./commit-guard scan
./commit-guard scan --threshold medium

1-Click Auto-Fix

./commit-guard scan --fix --dry-run
./commit-guard scan --fix

Dependency Blast-Radius

./commit-guard scan --dep-graph
./commit-guard scan --dep-graph-format all

Control Center Web GUI

./commit-guard gui
./commit-guard gui --port 8765

Repository Health Doctor

./commit-guard doctor
./commit-guard status

Pull Request Automation

./commit-guard scan --create-pr
./commit-guard scan --review-pr
